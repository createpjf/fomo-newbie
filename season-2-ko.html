01 — 핵심 규칙

지정 모델 ID만 인정됩니다

사용량은 오늘(5/22)부터 Season 2에 집계됩니다 — 월요일까지 기다릴 필요 없습니다. S2는 5/25 정식 시작. 핵심은: 아래 표의 지정 모델 ID(apiPlatformId)로 호출해야만 인정되며, 해당 Model Token($MT)에서 두 가지 보상(스테이킹 부스트 + 일일 emission)을 받습니다. 모델 원래 이름이나 다른 이름으로 호출하면 이번 시즌에는 집계되지 않습니다.

1단계 · 올바른 모델 ID 사용

AI를 호출할 때 모델 이름을 아래 표 오른쪽의 지정 모델 ID로 설정하세요(예: gemini-3.5-flash-flocklife). 코드를 몰라도 참여 가능 — 사용량은 API Key 기준으로 귀속됩니다: Key를 개발자에게 맡기거나 AI가 필요한 사람에게 공유하면 그들의 호출이 모두 내 보상에 반영됩니다.

2단계 · 해당 토큰 스테이킹

각 AI 모델에는 고유 토큰(Model Token, $MT)이 있습니다. 사용 중인 $MT를 스테이킹(락업)하면 같은 사용량으로 더 많은 보상을 받습니다.

3단계 · 일일 보상 수령

사용량이 많을수록 + 스테이킹할수록 일일 토큰 보상이 커집니다.

03 — 호출 예시

개발자를 위한 호출 예시

개발자용 예시입니다: "model"을 원하는 지정 모델 ID로, sk-xxxx를 본인 API Key로 바꾸세요. 코드를 모르신다면 이 코드를 개발자에게 맡기거나 FOMO 플랫폼에서 직접 모델을 사용해도 동일하게 사용량이 쌓입니다.

cURL · api.flock.io 
curl --location 'https://api.flock.io/v1/chat/completions' \
--header 'Content-Type: application/json' \
--header 'Authorization: Bearer sk-xxxxxxxxxxx' \
--data '{
    "model": "gemini-3.5-flash-flocklife",
    "messages": [
        {
            "role": "system",
            "content": "You are a funny and technical assistant."
        },
        {
            "role": "user",
            "content": "Hello"
        }
    ],
    "temperature": 0.1
}'

전체 규칙은 공식 문서를 참고하세요: docs.flock.io/flock-tokenomics/network-participation/fomo

04 — 보상 프레임워크 (S1과 동일)

보상 규모를 정하는 세 가지

Season 2는 Season 1의 논리를 유지합니다: 실제로 AI를 사용하면 계속 보상을 받습니다. 아래는 큰 틀이며, 구체적 수치(모델별 배분 비율, emission 주기, gmFLOCK 배수 등)는 5/25 공식 발표 기준입니다.

많이 쓸수록 많이 받습니다

특정 모델에서 받는 보상은 그 모델에서의 지출 비중에 비례합니다 — 실사용을 보상하며, 봇 어뷰징이 아닙니다.

$MT 스테이킹 부스트

사용 중인 모델의 Model Token($MT)을 스테이킹(락업)하면 같은 지출로 더 많이 받습니다. 일찍 스테이킹할수록 우위가 커집니다.

gmFLOCK · 전체 VIP 패스

$FLOCK을 스테이킹하면 gmFLOCK을 받습니다 — 모든 모델의 점수를 한꺼번에 키워 주는 전체 VIP 패스와 같습니다.

참고: 위는 큰 틀이며, Season 2의 정확한 가중치와 emission 세부사항은 5/25 전후 공식 발표되고 본 페이지도 업데이트됩니다. 본 페이지는 교육용이며 투자 조언이 아닙니다.
