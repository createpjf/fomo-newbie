자세한 계산 보기

MT별로 따로 계산합니다. 내 보상 지분 = 내 해당 점수 ÷ 그 MT의 모든 참여자 해당 점수 합계.

Global FLOCK

사용 점유율 × [α + (1 − α) × √스테이킹 비율] × gmFLOCK 배율

Reserved FLOCK ＋ MT 보상

사용 점유율 × 스테이킹 비율 × gmFLOCK 배율

  • 사용 점유율 = 내 API 지출 ÷ 해당 MT의 총 API 지출.
  • 스테이킹 비율 = 내가 스테이킹한 MT ÷ 해당 MT의 총 스테이킹량.
  • 초기 α는 약 0.9로 예상되며 변경될 수 있습니다. 인터랙티브 그래프의 값은 예시입니다.
  • gmFLOCK 배율의 개념식은 1 + λ × G입니다. G는 유효 잔액에 따라 증가하되 증가 폭은 줄어들며, λ는 프로토콜이 정합니다. 개념도는 정확한 프로토콜 계산식이 아닙니다.

자주 묻는 질문

세 가지 보상은 어떻게 다른가요?

Global FLOCK은 API 사용에 따라 각 MT에 배분된 뒤 Global 점수에 따라 참여자에게 분배됩니다. Reserved FLOCK은 해당 MT의 추가 FLOCK 풀이며, MT 보상은 모델의 자체 토큰입니다. 뒤의 두 풀은 보통 약 180일에 걸쳐 지급됩니다.

사용했는데 왜 반영되지 않나요?

API 호출의 모델 ID가 대상 MT와 일치하는지 확인하세요. 같은 모델도 여러 배포가 있을 수 있습니다. 다른 배포의 사용량은 이 MT의 사용 점유율에 합산되지 않습니다.

보상은 어디서 확인하나요?

FOMO에서 실제 보상을 확인하세요. FLOCK은 하나의 청구 가능 잔액에 합산되고, MT 보상은 토큰별로 표시됩니다. 잔액이 그대로라면 지난 계산에서 새 보상이 없었을 수 있습니다.
