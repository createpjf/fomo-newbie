查看详细计算

每个 MT 单独计算。你的奖励份额 = 你的对应分数 ÷ 该 MT 所有参与者的对应分数之和。

全局 FLOCK

使用份额 × [α + (1 − α) × √质押份额] × gmFLOCK 加成

预留 FLOCK ＋ MT 奖励

使用份额 × 质押份额 × gmFLOCK 加成

  • 使用份额 = 你的 API 支出 ÷ 该 MT 的 API 总支出。
  • 质押份额 = 你的 MT 质押量 ÷ 该 MT 的总质押量。
  • α 初期预计约为 0.9，后续可能调整；互动图中的参数均为示例。
  • gmFLOCK 加成概念式为 1 + λ × G；G 按有效余额递减增长，λ 由协议设定。示意曲线不是协议的精确计算公式。

你可能还想知道

三类奖励分别是什么？

全局 FLOCK 先按 API 使用分给各 MT，再按全局分数分给参与者。预留 FLOCK 是该 MT 的额外 FLOCK 池；MT 奖励发放该模型的代币。后两类通常在约 180 天内释放。

用了模型，为什么没计入？

确认 API 调用的模型 ID 与目标 MT 对应。同一个模型可能有不同部署，使用另一个部署不会增加这个 MT 的使用份额。

奖励在哪里看？

在 FOMO 查看实际奖励。FLOCK 汇入统一可领取余额，MT 奖励按代币分别显示。余额没有增加，可能是上一轮没有新增奖励。
